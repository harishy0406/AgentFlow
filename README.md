# AgentFlow
 Dependency-Aware Multi-Agent LLM Framework for  Automated Software Engineering Artifact Generation

Modern software teams still produce requirements, design, database, and API artifacts through manual, disconnected authoring, so a single requirement change forces later documents to be reproduced from scratch. Existing multiagent LLM systems automate this pipeline end-to-end but either regenerate everything on every edit or leave documents static once produced, and existing LLM routers select models using generic difficulty scores rather than artifactspecific quality signals. This project presents AgentFlow, a multi-agent software engineering system that models each generated artifact — PRD, SDD, database schema, API specification, user stories, and task breakdown — as a node in a typed dependency graph. When a requirement changes, AgentFlow recomputes only the affected downstream artifacts through diff aware prompting instead of regenerating the full pipeline, and routes each artifact type to the most suitable LLM using structured, artifact-specific quality signals. A dedicated consistency auditor detects drift between related documents and triggers only the targeted regeneration needed to fix it. The system is evaluated against a single-LLM baseline and a standard multi-agent pipeline without dependency tracking, measuring cost, latency, artifact quality, cross-document consistency, and regeneration efficiency after requirement changes.
